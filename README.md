# دار الرموز العربية: الفهرس الإلكتروني

فهرس إلكتروني لمكتبة، مبني بـ Next.js 15 (App Router) وSupabase (قاعدة Postgres وتسجيل الدخول وتخزين صور الأغلفة).

## التشغيل لأول مرة

### 1. إنشاء مشروع Supabase

1. أنشئ مشروعًا جديدًا من [supabase.com](https://supabase.com).
2. افتح **SQL Editor** وشغّل محتوى الملفات التالية بالترتيب:
   - `supabase/migrations/0001_init.sql`: ينشئ الجداول وقواعد الأمان (RLS) ومخزن صور الأغلفة.
   - `supabase/seed.sql` (اختياري): يضيف 33 كتابًا تجريبيًا.

### 2. إنشاء حساب المدير

1. من **Authentication → Users** اضغط **Add user** وأنشئ مستخدمًا ببريد وكلمة مرور.
2. في **SQL Editor** شغّل الأمر التالي بعد وضع البريد الصحيح:

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'admin@example.com';
```

أي حساب غير موجود في جدول `admins` يستطيع تسجيل الدخول، لكنه لا يستطيع التعديل على أي شيء.

### 3. ربط المشروع وتشغيله

انسخ `.env.example` إلى ملف جديد باسم `.env.local`، ثم ضع فيه الرابط والمفتاح من **Project Settings → API**.

```bash
npm install
npm run dev
```

بعدها افتح الروابط التالية:

- الفهرس: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin (لا يظهر رابطها في الموقع؛ يفتحها المدير مباشرة)

## بنية المشروع

```
app/
  page.tsx                     الفهرس: البحث والفلاتر وبطاقات الكتب
  books/[id]/page.tsx          تفاصيل الكتاب (بطاقة الفهرسة)
  admin/login/                 دخول المدير
  admin/(dash)/page.tsx        جدول الكتب (تعديل وحذف)
  admin/(dash)/books/new       إضافة كتاب
  admin/(dash)/books/[id]/edit تعديل كتاب
  admin/(dash)/authors|publishers|categories  إدارة القوائم
  admin/actions.ts             كل عمليات الكتابة (Server Actions)
components/                    واجهات مشتركة (Catalog, BookForm, Cover…)
lib/                           عملاء Supabase، والأنواع، والتحقق، وتوحيد النص العربي
supabase/                      ملف المخطط وملف البيانات التجريبية
```

## قرارات مهمة

- **الأمان في قاعدة البيانات:** القراءة متاحة للجميع، والكتابة للمديرين فقط عبر RLS، فلا يعتمد الأمان على الواجهة وحدها.
- **كلمة المرور لا تُخزَّن في جداولنا:** يتولاها Supabase Auth مشفّرة، بدل جدول Admin الذي يحفظ كلمة المرور كنص.
- **حماية الروابط:** لا يمكن حذف كاتب أو دار نشر أو تصنيف ما دامت له كتب (`on delete restrict`)، والواجهة تعطّل زر الحذف وتعرض عدد الكتب المرتبطة.
- **البحث العربي:** يوحّد النظام الحروف قبل المقارنة (أ/إ/آ ← ا، ة ← ه، ى ← ي) ويحذف التشكيل، فـ«احمد» تطابق «أحمد».
- **حالة البحث في الرابط:** البحث والفلاتر تُحفظ في عنوان الصفحة، فيمكن مشاركة نتيجة بحث، وزر الرجوع من صفحة الكتاب يعيدك إلى النتائج نفسها.
- **الفلترة في المتصفح:** يُحمَّل الفهرس مرة واحدة ثم تتم الفلترة فورًا دون انتظار الخادم، وهذا مناسب حتى بضعة آلاف من الكتب. إذا كبر الفهرس أكثر، تُنقل الفلترة إلى Postgres (بالبحث النصي `pg_trgm` مع عمود نص موحّد).
